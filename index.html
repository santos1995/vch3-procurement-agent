ProcureAssist

AI-assisted procurement: site requirement → vendor comparative. VCH3, 21 Nov 2026 · Vinayak Group statement

Demo build with synthetic vendors and quotes. Structuring and quote-reading are currently rule-based pattern matching, not an AI model; an AI provider is added only if a free option verifies. RFQs are drafts for test inboxes only — no real vendor is ever contacted. The agent recommends; a human makes the final call.

1Site requirement

Paste the site engineer's message as-is (WhatsApp text or voice-note transcript), or load the sample.

2Structured requirement & item code

Extracted fields, matched to the item master. Duplicates flagged; a new code is suggested if nothing matches.

3RFQ drafts

Drafts for the right vendors for this category. DRAFT - test inboxes only, nothing is sent

4Vendor replies → normalized

Replies arrive in any format. Load the demo replies (three different formats) or paste your own, then normalize.

5Comparative statement

Landed price = normalized rate × qty + freight + GST (only when quoted extra) − discount. Missing terms are flagged, never assumed. Ranking: 70% landed price + 30% past performance.

6Recommendation to HOD

The agent recommends with its reasoning. It does not select, order or pay — the HOD decides.
